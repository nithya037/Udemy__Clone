**Udemy Website Clone**

A static, responsive clone of the Udemy website built using HTML5 and CSS3. This project focuses on semantic HTML structure, responsive layouts using Flexbox and Grid, and recreating key sections of Udemy, including the navigation bar, menu, recommended courses, popular topics, trending courses, and footer.

**Technologies:** HTML5, CSS3, Flexbox, CSS Grid, Responsive Web Design.

**Objective:** Practice front-end development skills by recreating a real-world website layout.

**Reference:** https://www.udemy.com/
